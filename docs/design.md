# OS City pilot direction

The original OS City panorama and the three guardians become a playable comic cover. The live interaction is the pilot's deterministic 30-second timeline.

Inventory: Commander Kernel's cyan coat; Agent Patch's yellow jacket and magenta hair; Captain Firewall's red shield; the OS City skyline; holographic locks; data folders; server racks; 30-second running time; three security principles; comic halftones; a final security alert.

Direction: Loud and flat, seed 1060227370. The supplied poster determines the centered cover composition so that none of the three illustrated characters is covered by the title. Supplied comic styling takes precedence over general marketing-page rules: neon colors, speech-bubble outlines, halftones, and hard comic shadows are intentional. No stock photography or generated replacement art is used.

Copy and sequence: OS CITY / UNDER ATTACK → Start Story. City introduction → responsible resource use → confidentiality, integrity, availability → definitions → security alert. Definitions use authorized access explicitly. No claim is made that voiceover timing is validated.

The 1920×1080 stage uses contain scaling and letterboxing. Portrait phones use the same artboard plus a separate, readable live dialogue area. Reduced motion disables idle movement, camera travel, character slides, ambient poster drift, and effect rotation. Settings freezes the GSAP clock. Changing a visual preference while paused intentionally redraws at the same timestamp.

Source art limitations: flattened poses allow transform animation, not independent limb/hair rigging. Generated poses vary slightly in proportions. The panorama is used alone, avoiding doubled skyline layers. Full-story adversaries and recorded audio remain outside this pilot.
